# 项目开发规范

## 代码理解优先原则

当遇到不熟悉的代码或第三方库时，请遵循以下步骤：

1. **先查项目文档** - 使用 DeepWiki MCP 查看相关 GitHub 项目的文档
   - 调用 `deepwiki` 工具获取项目结构和文档
   - 理解 API 设计和使用方式

2. **网页分析** - 使用 Chrome DevTools MCP 分析网页行为
   - 查看网络请求和响应
   - 检查控制台日志
   - 分析页面结构

3. **再动手写代码** - 在充分理解后再进行实现

## 可用的 MCP 工具

- `deepwiki` - 查看 GitHub 项目文档，理解代码结构
- `chrome-devtools` - 网页调试和分析
- `zeabur` - 部署服务
- `puppeteer` - 浏览器自动化
