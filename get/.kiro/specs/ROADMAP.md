## 开发批次详情

### 第一批：基础层 (2025 Q1-Q2)

| Spec | 状态 | 核心功能 | 技术栈 |
|------|------|---------|--------|
| `openbb-integration` | ✅ 已完成 | 统一数据获取、多源聚合、FastAPI 服务 | Python + OpenBB + FastAPI |
| `risk-control-2026` | ✅ 已完成 | 杠杆/回撤/连败熔断规则 | TypeScript |

**依赖关系**: 无外部依赖，可并行开发

---

### 第二批：实时行情平台 (2025 Q2)

| Spec | 状态 | 核心功能 | 技术栈 |
|------|------|---------|--------|
| `realtime-market-platform` | ✅ 已完成 | WebSocket 推送、价格警报、前端组件 | TypeScript + React |

**依赖关系**: 依赖 `openbb-integration` 提供数据

**架构变更**:
- 通过 OpenBB Client 获取美股备用数据
- 保留长桥 API 作为主数据源
- 保留腾讯财经作为 A 股数据源

---

### 第三批：量化分析层 (2025 Q3)

| Spec | 状态 | 核心功能 | 技术栈 |
|------|------|---------|--------|
| `qlib-analytics` | ✅ 已完成 | 波动率预测、回撤概率、市场状态分类 | Python + Qlib + MLflow |

**依赖关系**: 依赖 `openbb-integration` 提供历史数据

**核心模型**:
1. 波动率预测模型 (GARCH + LSTM 集成)
2. 回撤概率模型 (蒙特卡洛模拟)
3. 市场状态分类器 (隐马尔可夫模型)

---

### 第四批：智能风控引擎 (2025 Q4)

| Spec | 状态 | 核心功能 | 技术栈 |
|------|------|---------|--------|
| `intelligent-risk-engine` | ✅ 已完成 | 动态阈值、AI 预警、仓位优化 | TypeScript |

**依赖关系**: 依赖 `qlib-analytics` 提供预测结果

**核心功能**:
1. 动态杠杆限制 (基于市场状态自动调整 1.0x ~ 1.5x)
2. 动态止损线 (基于波动率调整 -8% ~ -15%)
3. 风险预警系统 (提前 1/3/5 天预警)
4. 情绪化交易检测 (报复性交易、过度交易)
5. 仓位优化建议 (基于风险预算)

## 技术栈总览

| 层级 | 语言 | 框架/库 | 部署 |
|------|------|---------|------|
| 前端 | TypeScript | React + Vite + TailwindCSS | Vercel |
| 后端 API | TypeScript | Hono (现有) | Vercel Functions |
| 数据服务 | Python | OpenBB + FastAPI | 独立服务 |
| 量化分析 | Python | Qlib + MLflow | 独立服务/定时任务 |
| 数据库 | SQL | Supabase (PostgreSQL) | Supabase Cloud |
