# QA 验证规则

## 最高指令

**禁止未经验证就汇报"完成"。**

## 执行流程

```
编码 → 运行 → 验证 → 通过? → 汇报
                ↓
              失败 → 静默修复 → 重新运行
```

### 验证要求

1. **检查日志**：无 Error、无 Warning
2. **检查结果**：输出符合预期
3. **自问**：交给用户会不会被骂？

### 前端功能必须

- **使用 Playwright 测试验证**
- 确认页面渲染正确
- 确认交互功能正常
- 截图或日志作为证据

## 汇报格式

只有 100% 确认通过后：

```
✅ [Verified] 任务完成，已通过测试。
```

## 禁止行为

| ❌ 禁止 | ✅ 正确 |
|--------|--------|
| 假设运行成功 | 检查实际输出 |
| 报错后汇报完成 | 静默修复后重试 |
| 跳过前端测试 | Playwright 验证 |
| 发送半成品 | 反复修复直到正确 |
