# 开源项目评估清单

> 搬运前的详细评估流程

## 快速评估（5分钟）

### 基础指标
- [ ] Stars > 100
- [ ] 最近 6 个月有更新
- [ ] 有 README 文档
- [ ] 有明确的许可证
- [ ] 无重大安全漏洞

### 快速检查命令
```bash
# 检查 npm 包信息
npm view <package> 

# 检查包大小
npx bundlephobia <package>

# 检查安全漏洞
npm audit <package>
```

## 深度评估（30分钟）

### 1. 活跃度评估

| 指标 | 检查方法 | 合格标准 |
|------|----------|----------|
| 提交频率 | GitHub Insights | 每月有提交 |
| Issue 响应 | 查看 Issues | 7天内有回复 |
| PR 合并 | 查看 PRs | 有合并记录 |
| 发布频率 | Releases 页面 | 每季度有发布 |
| 维护者数量 | Contributors | >2 人 |

### 2. 代码质量评估

| 指标 | 检查方法 | 合格标准 |
|------|----------|----------|
| TypeScript | 查看源码 | 有类型定义 |
| 测试覆盖 | 查看 CI | >60% |
| 代码风格 | 查看配置 | 有 ESLint/Prettier |
| 文档注释 | 查看源码 | 关键函数有注释 |
| 错误处理 | 查看源码 | 有完善的错误处理 |

### 3. 生态系统评估

| 指标 | 检查方法 | 合格标准 |
|------|----------|----------|
| 下载量 | npm stats | >1000/周 |
| 依赖数量 | package.json | <20 |
| 被依赖数 | npm dependents | >10 |
| 社区支持 | Discord/Slack | 有活跃社区 |
| 文档质量 | 官方文档 | 有完整示例 |

### 4. 兼容性评估

| 指标 | 检查方法 | 合格标准 |
|------|----------|----------|
| Node 版本 | engines 字段 | 支持 LTS |
| 浏览器支持 | browserslist | 支持主流浏览器 |
| 框架兼容 | 文档/Issues | 与项目框架兼容 |
| 依赖冲突 | npm ls | 无版本冲突 |

## 红旗警告（立即放弃）

遇到以下情况，立即寻找替代方案：

- 🚩 超过 1 年没有更新
- 🚩 有未修复的安全漏洞
- 🚩 核心维护者已离开
- 🚩 GPL/AGPL 许可证（商业项目）
- 🚩 依赖数量 > 50
- 🚩 无任何测试
- 🚩 文档严重缺失
- 🚩 Issues 堆积无人处理
