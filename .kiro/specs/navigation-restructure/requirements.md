# 导航重构需求文档

## 背景

当前侧边栏有 15+ 个入口，功能分散且层级混乱。需要精简为清晰的 5 个主入口 + 1 个工具箱。

## 目标

1. 减少认知负担，让用户快速找到核心功能
2. 将低频功能收纳到"工具"中
3. 合并同类功能（闪念/笔记/待办）

## 新导航结构

```
═══════════════════════
🏠 首页
─────────────────────── 
📝 笔记  [闪念 | 笔记 | 待办]  ← Tab 切换
📁 文件
───────────────────────
🤖 Echo AI
🔍 搜索
───────────────────────
🧰 工具
   ├─ 统计
   ├─ 翻译
   ├─ 资源
   ├─ 活动监控
   ├─ 自动化
   ├─ Janitor
   ├─ Agent 管理
   └─ 系统设置
═══════════════════════
```

## 功能映射

| 原功能 | 新位置 | 说明 |
|--------|--------|------|
| 闪念 (blinko) | 笔记 Tab | 合并为笔记的子视图 |
| 笔记 (notes) | 笔记 Tab | 合并为笔记的子视图 |
| 待办 (todo) | 笔记 Tab | 合并为笔记的子视图 |
| 翻译 | 工具 | 低频功能 |
| 活动监控 | 工具 | 低频功能 |
| 统计 | 工具 | 低频功能 |
| 资源 | 工具 | 低频功能 |
| 文件 | 主导航 | 保留 |
| EchoAI 首页 | 首页 | 作为应用首页 |
| EchoAI 对话 | Echo AI | 主导航 |
| EchoAI 搜索 | 搜索 | 主导航 |
| AI Agents | 工具 > Agent 管理 | 低频配置 |
| 自动化任务 | 工具 > 自动化 | 低频配置 |
| 归档 | 工具 | 低频功能 |

## 验收标准

1. 侧边栏只显示 5 个主入口 + 工具箱
2. 笔记页面支持 Tab 切换（闪念/笔记/待办）
3. 工具箱可展开/收起
4. 所有原有功能仍可访问
5. 移动端适配
